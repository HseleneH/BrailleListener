### 1. 開發工具

盲文（點字）網站的設計，通常還是使用 HTML、CSS 和 JavaScript 來開發。但是，為了讓盲人（使用螢幕閱讀器）能夠無障礙地訪問網站，我們需要遵循無障礙網頁設計規範（如 WCAG 2.1）。此外，也可以考慮提供專門的點字（Braille）顯示支援，但這通常需要特殊的硬體設備和軟體支援。在網頁上，我們主要確保內容可以被轉換成點字（通過螢幕閱讀器轉譯給點字顯示器）。

### 2. 無障礙網站設計規則

無障礙網頁設計的主要國際標準是 WCAG（Web Content Accessibility Guidelines）。以下是具體的分項（基於 WCAG 2.1 的四個原則：可感知、可操作、可理解、穩健）以及一些具體要求：

#### 原則一：可感知（Perceivable）
**資訊及使用者介面元件應以使用者能察覺之方式呈現。**
就算使用者只能使用部分感官他也要可以感知察覺到網頁裡的資訊

- **文字替代（Text Alternatives）**：為非文字內容（如圖片、圖表）提供替代文字（alt text）。
- **時間媒體（Time-based Media）**：為音頻和視頻提供字幕、手語翻譯或文字記錄。
- **適應性（Adaptable）**：創建可以不同方式呈現（例如更簡單的佈局）的內容而不丟失信息。
- **可辨識（Distinguishable）**：讓用戶更容易看到和聽到內容。

#### 原則二：可操作（Operable）
**使用者介面元件及導覽功能應具可操作性。**
要兼顧只使用鍵盤操作或語音輸入的人

- **鍵盤可訪問（Keyboard Accessible）**：所有功能都可以通過鍵盤操作。
- **足夠時間（Enough Time）**：給用戶足夠的時間閱讀和使用內容。
- **不會引發癲癇（Seizures and Physical Reactions）**：不要設計會引發癲癇發作的內容（如閃光）。
- **易於導航（Navigable）**：提供幫助用戶導航、查找內容和確定位置的方法（例如跳過連結、標題、地標標籤）。

#### 原則三：可理解（Understandable）
**資訊及使用者介面之操作應具可理解性。**
網頁內容和網頁介面介面操作的方式，都不能超出使用者的理解

- **可讀（Readable）**：使文本內容可讀且可理解。
- **可預測（Predictable）**：使網頁的外觀和操作具有可預測性。
~~- **輸入輔助（Input Assistance）**：幫助用戶避免和糾正錯誤（如表單驗證和提示）。~~

#### 原則四：穩健（Robust）
**網頁內容應可供身心障礙者以輔助工具讀取，並具有相容性。**

~~- **相容（Compatible）**：確保與當前和未來的用戶代理（包括輔助技術）相容（例如使用標準HTML標籤和ARIA）。~~

### 3. 政府網站範例與講解

在台灣，政府網站需要遵循無障礙規範（通常參考 WCAG 2.0 Level AA）。你可以參考「台灣無障礙網路空間服務網」：[台灣無障礙網路空間服務網](https://accessibility.moda.gov.tw/)

我們以「台灣無障礙網路空間服務網」為例，但注意：我們無法直接查看其原始碼（除非公開），但可以通過瀏覽器的開發者工具查看。

常見的無障礙設計實作：

- **地標（Landmarks）**：使用ARIA地標角色（role）或HTML5語義標籤（如`<header>`, `<nav>`, `<main>`, `<footer>`）來標記網頁區域。

- **跳過連結（Skip Link）**：在頁面頂部提供一個跳過導航直接到主要內容的連結（通常隱藏，但在鍵盤聚焦時顯示）。

- **標題結構（Heading Structure）**：使用`<h1>`到`<h6>`的標題層級，確保層次正確。

- **替代文字（Alt Text）**：所有有意義的圖片都應有`alt`屬性；裝飾性圖片則使用`alt=""`。

~~~- **表單標籤（Form Labels）**：每個表單輸入元素都應有對應的`<label>`。~~~

- **ARIA（Accessible Rich Internet Applications）**：當標準HTML元素不足以表達語義時，使用ARIA角色（role）和屬性（如`aria-label`, `aria-describedby`）來增強可訪問性。

- **鍵盤導航**：確保所有互動元素（連結、按鈕、表單）都可以通過鍵盤（Tab鍵）訪問，並有可見的聚焦狀態。

### 如何添加到HTML上？

以下是一些具體的實作方法：

#### 替代文字（Alt Text）

```html

<img src="logo.png" alt="公司標誌">

```

#### 地標（Landmarks）

```html

<header role="banner">

<!-- 頁首內容 -->

</header>

<nav role="navigation">

<!-- 導航連結 -->

</nav>

<main role="main">

<!-- 主要內容 -->

</main>

<footer role="contentinfo">

<!-- 頁尾內容 -->

</footer>

```

#### 跳過連結（Skip Link）

```html

<a class="skip-link" href="#main-content">跳過導航</a>

...

<main id="main-content">

<!-- 主要內容 -->

</main>

```

CSS:

```css

.skip-link {

position: absolute;

top: -40px;

left: 0;

background: #000;

color: white;

padding: 8px;

z-index: 100;

}

.skip-link:focus {

top: 0;

}

```

#### 使用ARIA增強

例如，一個按鈕打開一個對話框：

```html

<button aria-expanded="false" aria-controls="dialog1">打開對話框</button>

<div id="dialog1" role="dialog" aria-labelledby="dialog-title" hidden>

<h2 id="dialog-title">對話框標題</h2>

<p>對話框內容...</p>

</div>

```

然後用JavaScript控制`aria-expanded`和`hidden`屬性。

### 針對台灣盲人

台灣的盲人使用中文，因此螢幕閱讀器通常是中文的（如NVDA搭配中文語音）。在設計時，除了遵循國際標準外，還需要注意：

- 語言標記：在`<html>`標籤上設置`lang="zh-TW"`。

- 中文字體的選擇：確保字體清晰，並且在放大時不會失真。

- 避免使用過多的圖片代替文字，特別是重要的文字內容。
